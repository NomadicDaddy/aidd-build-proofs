# Security policy

This repository publishes sanitized historical build evidence. A missed credential, private path,
machine identifier, personal address, private network address, or unrelated project reference is a
security and privacy issue even when it appears only in a transcript archive.

Do not open a public issue containing the exposed value. Use GitHub private vulnerability reporting
through **Security → Report a vulnerability** and include the affected path or release asset and
enough context to locate the material without repeating the sensitive value unnecessarily.

The maintainer will remove or replace affected release assets, rotate exposed credentials where
applicable, and publish corrected checksums and indexes. Historical source snapshots are otherwise
immutable; corrections to prose or evidence metadata will be documented in the repository history.

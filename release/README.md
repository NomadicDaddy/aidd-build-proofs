# Release evidence

The `v1.1.0` GitHub release publishes the archive this tree's index and checksums describe, for
all seven proofs:

- `aidd-build-proofs-transcripts.zip` (279 transcripts)
- `transcript-index.json`
- `SHA256SUMS.txt`

The earlier `v1.0.0` release remains published with the archive of the original four-proof
campaign, `aidd-build-proofs-2026-07-transcripts.zip`. Its assets match those four proofs, not this
tree's index.

The transcript index is tracked here so repository verification can validate the public provenance
metadata. The zip itself remains a release asset rather than a Git blob.

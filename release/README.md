# Release evidence

The `v1.0.0` GitHub release publishes the archive of the original four-proof campaign:

- `aidd-build-proofs-2026-07-transcripts.zip`
- `transcript-index.json`
- `SHA256SUMS.txt`

This tree describes the later seven-proof collection. Its `transcript-index.json` and
`SHA256SUMS.txt` name `aidd-build-proofs-transcripts.zip` (279 transcripts), which is not yet
published as a release asset. Until it is, the v1.0.0 assets match the four original proofs, not
this tree's index.

The transcript index is tracked here so repository verification can validate the public provenance
metadata. The zip itself remains a release asset rather than a Git blob.
